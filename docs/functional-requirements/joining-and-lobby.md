# Joining and Lobby

## Overview

Players reserve a place in a game's lobby with a PIN and a unique handle, while the
host receives authoritative presence updates and can remove players.

## User Stories

### US-010: Join a live game

**As a**
player

**I want**
to join a lobby using a PIN and handle name

**So that**
I can participate in the host's game.

### US-011: Manage the lobby

**As a**
host

**I want**
to see current player presence and remove inappropriate players

**So that**
I can prepare a suitable group before starting.

## Acceptance Criteria

- Given a valid PIN for a game in `LOBBY`, when a player supplies a valid unique handle, then a seat is reserved in that game.
- Given a reserved player, when the player attaches through the realtime hub by `JoinGame` or `Reconnect`, then the host receives `ParticipantPresenceChanged`.
- Given a REST-only join, when no hub attachment has occurred, then no presence event is broadcast and the host can recover current presence through `GET /api/games/{id}`.
- Given a player in the lobby, when the host removes that player, then the player cannot rejoin the same game with the same handle.

## Business Rules

### FR-5: Joining a game

- Players join with a game PIN, embedded in a shared link or entered on the join page, and a handle name.
- PINs are short, generated by the server, and unique among unfinished games.
- Handle names are unique within a game without regard to case and must pass validation and sanitization.
- Games have no artificial participant limit and accept a dynamically increasing number of participants, including more than 500, subject only to platform resources.
- A REST join reserves a seat; successful hub attachment establishes presence.

## Edge Cases

- A join is rejected for an invalid PIN, a game outside `LOBBY`, a duplicate case-insensitive handle, or a duplicate session.
- After a game starts, new joins are rejected.
- Disconnecting or removing a player after the game starts does not create a joinable seat.
- A player removed by the host cannot reclaim the same handle in that game.
