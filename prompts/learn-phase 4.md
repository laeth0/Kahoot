| Concept | Brief Meaning |
|---|---|
| **Atomic Deep Snapshot on Write** | Copying an entire entity graph (quiz → questions → choices → image refs) into immutable snapshot tables within a single database transaction at launch time, so future mutations to the source never affect in-flight reads of the snapshot. |
| **Technical Safety Bound (200-Item Hard Cap)** | Imposing a fixed upper limit on a collection size (e.g., 200 questions) as a system-safety measure to bound worst-case memory allocation, serialization payload size, and snapshot-generation latency ($p95 \le 200\text{ ms}$) — not a product quota. |
| **Monotonic Revision Tracking (Optimistic Concurrency)** | Incrementing a server-assigned `Revision` counter on every successful write so clients can detect conflicts with a `409` on stale-version submissions, eliminating lost updates without pessimistic locks. |
| **Atomic Child-Set Replacement** | Replacing an entire child collection (e.g., all choices for a question) atomically in one transaction — deleting old rows and inserting new ones together — to prevent partial states, orphaned records, or violated uniqueness constraints. |
| **Tenant-Matched Composite Foreign Key** | Enforcing ownership of a cross-entity reference (e.g., `imageId`) via a composite foreign key on `(ImageId, HostAccountId)` rather than `ImageId` alone, making it structurally impossible for the database to store a cross-tenant reference even if application-layer checks are bypassed. |
| **Transactional Row Lock to Serialize Concurrent Writers** | Acquiring an explicit row-level lock (e.g., `SELECT ... FOR UPDATE`) on the parent entity before any child mutation or snapshot generation, serializing concurrent writers and preventing partial or inconsistent snapshot capture. |
| **Stored XSS Prevention via Plain-Text Column Type** | Storing user-supplied text content in plain scalar columns (not HTML or rich-text columns) and HTML-encoding on every rendering path, so no stored content can ever be interpreted as executable script by a client. |
